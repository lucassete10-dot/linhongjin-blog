# Help Myself 页面与交互蓝图

## 1. 信息架构

```text
Help Myself
├─ 首页
├─ 文章
│  ├─ 文章列表
│  └─ 文章详情
├─ AI 工具
│  ├─ 工具分类与搜索
│  └─ 工具详情
├─ 播客感悟
│  ├─ 感悟列表
│  └─ 感悟详情
├─ 项目
│  ├─ 项目列表
│  └─ 项目详情
├─ 资源库
├─ 关于 Flora
├─ 全站搜索
└─ QQ 群入口
```

导航名称保持直白易懂，不使用需要猜测含义的游戏化名称。沉浸感主要通过视觉与转场表达。

## 2. 首页结构

### 第一幕：认识 Flora

- 全屏 Flora 冰雪晨光主视觉。
- 左侧仅显示网站名和口号 `Help myself, help others.`。
- 提供低干扰的向下探索提示。
- 桌面端可加入轻微雪粒、星光轨迹和景深移动。
- 移动端裁切时优先保留 Flora 面部、黑猫和口号区域。

### 第二幕：探索内容

用户向下滚动后，第一幕中的玻璃卡片向前展开，形成进入新空间的感觉。该区域包含：

1. 全站搜索
2. 最新文章
3. AI 工具导航
4. 资源库入口

转场建议控制在 600–900ms，并为系统开启“减少动态效果”的用户提供无动画版本。

### 第三幕：认识创作者

- 播客感悟
- 项目作品
- 关于 Flora 的简短说明
- QQ 群占位入口

页尾显示品牌名、口号和基础导航，不加入复杂营销信息。

## 4. 列表与详情页面

### 文章

- 列表显示标题、摘要、封面、分类、标签和发布日期。
- 详情页以简洁阅读为主，提供目录、正文、相关内容和分享入口。
- 不展示评论区、浏览量或虚假的互动数字。

### AI 工具

分类固定为：

- AI 工具使用体感
- AI 对话
- AI 用于自我提升的探索
- 学习
- 效率办公

工具卡片显示名称、图标、简短结论、推荐指数和适合人群。详情页固定展示：

- 使用体感
- Flora 的评价
- 使用教程
- 推荐指数
- 适合谁
- 官方访问入口

第一版不强调价格、复杂参数或竞品对照。

### 播客感悟

- 显示播客名称、单集名称、收听平台、记录日期和感悟摘要。
- 详情页明确区分播客原始信息与 Flora 的个人感悟。

### 项目

- 卡片显示项目封面、名称、简介、状态和标签。
- 详情页包含项目背景、截图、制作过程、遇到的问题、解决方式、在线体验和源码链接。

### 资源库

第一版展示设计完成的空状态，说明资源正在整理。后台保留资源管理入口，但前台不放置虚假下载按钮。

## 5. 搜索体验

- 搜索范围：文章、AI 工具、播客感悟和项目。
- 结果页可按内容类型筛选。
- 每条结果明确显示所属类型，避免不同内容混在一起难以判断。
- 无结果时推荐查看 AI 工具分类或最新文章。

## 6. 核心用户流程

### 内容发现

```text
社交媒体分享 / 直接访问
→ 首页认识 Flora
→ 搜索或选择内容分类
→ 打开文章、工具、播客或项目
→ 阅读相关内容
→ 查看其他内容或 QQ 群入口
```

### 内容发布

```text
管理员登录
→ 选择内容类型
→ 填写字段并上传图片
→ 保存草稿
→ 预览桌面端和移动端
→ 发布或置顶
→ 前台自动更新
```

## 7. 视觉系统

- 品牌角色：原创 Flora 与黑猫伙伴。
- 主色：冰雪蓝、奶油白。
- 强调色：星光金。
- 深色：夜空蓝与炭黑，用于玻璃卡片和正文文字。
- 气质：温暖、治愈、好奇、安静探索。
- 卡片：半透明玻璃质感，但正文阅读区保持足够不透明度和对比度。
- 字体：中文应优先保证长文可读性；标题可以更具柔和的个性。

品牌主视觉文件：`assets/brand/flora-hero-v1.png`。

## 8. 动效边界

- 首页首屏允许雪粒、星光和轻微视差。
- 首屏进入内容区时使用一次主转场，表达卡片进入新空间。
- 内容列表只使用轻微浮起和淡入。
- 文章页不使用持续移动背景。
- 移动端和低性能设备自动降低粒子数量和模糊强度。

## 9. 社交传播

- 分享标题：`Help Myself — Flora 的 AI 学习与探索空间`
- 分享描述：`Help myself, help others.`
- 分享图：以 Flora 主视觉为基础制作横版分享卡。
- 小红书、B站和抖音发布时优先使用首页首屏录屏或竖版裁切图。
- 朋友圈链接卡片保持标题短、主体清晰，不堆叠栏目名称。
