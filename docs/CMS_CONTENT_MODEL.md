# Help Myself 后台内容模型

## 1. 管理员与权限

第一版只有 Flora 一个管理员账号。

- 使用账号和密码登录。
- 不开放注册入口。
- 登录失败不泄露账号是否存在。
- 后台会话到期后需要重新登录。
- 发布、删除和修改首页信息都需要管理员权限。

## 2. 后台首页

后台首页显示：

- 草稿数量
- 已发布内容数量
- 最近编辑内容
- 快速新建文章、AI 工具、播客感悟和项目
- QQ 群与网站基础设置状态

不展示访客统计。

## 3. 通用内容字段

所有内容类型共享以下字段：

| 字段 | 用途 |
| --- | --- |
| 标题 | 前台主标题 |
| URL 标识 | 生成简洁、稳定的详情页地址 |
| 摘要 | 列表卡片和分享描述 |
| 封面图 | 列表、详情和分享展示 |
| 标签 | 搜索和相关内容 |
| 状态 | 草稿或已发布 |
| 是否置顶 | 控制首页和列表优先级 |
| 发布时间 | 控制展示顺序 |
| 更新时间 | 告知内容新鲜度 |
| SEO 标题与描述 | 搜索引擎展示信息 |

## 4. 文章字段

- 分类
- Markdown 正文
- 正文目录开关
- 相关内容
- 外部参考链接

Markdown 正文支持标题、列表、引用、代码块、表格、图片和链接。完整的 B站视频链接会自动转换为响应式播放器。

## 5. AI 工具字段

- 工具名称
- 工具图标
- 所属分类（可多选）
- 一句话结论
- 使用体感
- Flora 的评价
- 使用教程
- 推荐指数
- 适合人群
- 官方访问链接
- 相关内容

推荐指数应采用统一尺度，例如 1–5 星，并允许说明推荐理由，避免只展示数字。

## 6. 播客感悟字段

- 播客名称
- 单集名称
- 主播或嘉宾
- 原始收听链接
- 收听平台
- 收听日期
- 个人感悟正文
- 关键启发

## 7. 项目字段

- 项目名称
- 项目简介
- 项目状态
- 项目标签
- 项目背景
- 制作过程
- 遇到的问题
- 解决方式
- 项目截图集
- 在线体验链接
- 源码链接

链接允许暂时留空，前台不显示无效按钮。

## 8. 资源字段

资源库暂不启用真实内容，但预留：

- 资源名称
- 资源类型
- 简介
- 封面
- 来源与版权说明
- 外部链接或下载地址
- 使用说明
- 是否公开

只有来源和授权情况明确的资源才可发布。

## 9. 网站设置

后台可编辑以下全局信息：

- 网站名称
- 品牌口号
- Flora 简介
- 首页主视觉
- 分享图
- QQ 群号
- QQ 群二维码
- QQ 群状态（筹备中或已开放）
- 页脚信息

## 10. 编辑体验

- 编辑器同时支持正文、标题层级、列表、引用、链接、图片和代码块。
- 图片上传后自动生成适合网页的尺寸，保留原图但不直接加载超大文件。
- 草稿可以预览，预览页不得被搜索引擎收录。
- 删除操作需要二次确认，优先进入回收站而非立即永久删除。
- 示例内容必须显示“示例内容”标识，正式替换后可在后台关闭该标识。

## 11. 初始示例内容建议

每个主要栏目先放置 1–2 条示例：

- 文章：一篇 AI 学习记录、一篇效率学习心得。
- AI 工具：一个 AI 对话工具、一个效率办公工具。
- 播客感悟：一篇完整的收听记录。
- 项目：一个 Help Myself 网站项目记录。
- 资源库：使用空状态，不创建虚假资源。

示例正文必须明确说明内容用于展示页面结构，避免让访客误认为是真实评测。
