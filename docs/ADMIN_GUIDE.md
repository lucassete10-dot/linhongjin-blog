# Flora 后台使用说明

## 1. 登录

打开网站页尾的“管理后台”，使用 Supabase 中创建的 Flora 管理员邮箱和密码登录。

管理员账号不对访客开放注册。数据库的 RLS 策略会再次验证管理员身份，即使有人查看网页源代码或取得公开 anon key，也不能修改内容。

## 2. 发布内容

1. 点击“新建内容”。
2. 选择文章、AI 工具、播客感悟、项目或资源。
3. 填写标题、URL 标识、摘要、分类和 Markdown 正文。
4. 使用“编辑/预览”切换检查排版。
5. 需要封面时选择图片上传，单张不超过 5MB。
6. 选择“草稿”可继续修改；选择“发布”会立即出现在前台。
7. 点击“保存草稿”或“保存并发布”。

内容保存在 Supabase Postgres，封面保存在 `content-images` Storage bucket。

## 3. Markdown 与 B站视频

正文支持常用 Markdown：

````markdown
# 一级标题

## 二级标题

**粗体**、*斜体*、[链接](https://example.com)

- 无序列表
- 第二项

> 引用内容

```js
console.log('代码块')
```
````

将完整的 B站视频地址单独放一行即可自动显示播放器：

```text
https://www.bilibili.com/video/BV1xxxxxxxxx/
```

支持 BV 号、av 号和多 P 视频的 `?p=2` 参数。短链接 `b23.tv` 请先在浏览器中打开，再复制跳转后的完整 B站链接。

## 4. 主要字段

- URL 标识：只能使用小写英文字母、数字和连字符，例如 `my-first-ai-note`。
- 卡片眉题：标题上方的小字，例如“学习记录 · AI 入门”。
- 摘要：用于列表卡片和搜索结果。
- 标签：使用中文或英文逗号分隔。
- 置顶：首页和列表优先展示。
- 示例内容：提醒访客这篇内容仍是演示。
- AI 工具：额外填写推荐指数和适合人群。

## 5. 账号安全

- 使用独立的高强度密码，并保存在密码管理器中。
- 不要把密码、Supabase `service_role` 密钥或登录验证码发给任何人。
- 前端只允许使用 Publishable/anon key。
- 如果怀疑账号泄露，应立即在 Supabase Authentication 中修改密码并撤销会话。

## 6. 备份

内容和图片由 Supabase 托管。正式运营后应定期导出数据库内容，并保留重要原图的本地副本。
